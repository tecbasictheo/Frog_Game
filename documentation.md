# $\color{green}\Huge{Documentation}$

My idea just started with my liking of the game "Crossy Road" and then thinking if I could do it myself.\
I did not know the original frogger, the arcade game, beforehand. I found it while coding as I was looking up YouTube tutorials. Unintentional my game is quite similar to the original, this gave my game the name.  
I did not even steal the idea of using a frog character, I thought I was being original.\
